# Genlabor – DNA-Chip-Labor

Interaktive Lernanwendung zum DNA-Chip (DNA-Microarray) für die Oberstufe Biologie.

- Laborversuch in 5 Stationen: Reagenzien aus dem Regal wählen, Reaktion starten, Ergebnis ansehen
- Auswertung des Leuchtmusters, Anwendungsbeispiele (Brustkrebs/HER2, Hitzestress bei Weizen)
- Übungen: Befund → Leuchtmuster, Sequenz → Leuchtmuster, mRNA → cDNA → Sonde → Farbe
- Arbeitsblatt-Aufgaben und Zusatzaufgabe Leukämie

Aufruf: https://lernenmitspass.github.io/Genlabor/
